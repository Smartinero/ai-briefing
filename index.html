Introducing Claude Opus 4.8
Blog ⭐ High Relevance May 28 · ~6 min read
Major model and feature release. Key items for Sven's workflow:

Claude Opus 4.8 model: Better agentic judgment — more likely to flag uncertainties, 4× less likely to let code flaws pass unremarked. Improved consistency in long sessions. Available now at same pricing ($5/$25 per million tokens).

Dynamic Workflows (research preview): Claude Code can now plan a task and spawn hundreds of parallel subagents, then verify outputs before reporting back. Designed for codebase-scale migrations and large autonomous tasks. Available on Enterprise, Team, and Max plans.

Effort Control: New control in claude.ai and Cowork lets you choose how much effort Claude applies — higher effort = better responses, uses more of your rate limit; lower effort = faster, lighter. Available on all plans.

Fast Mode pricing: Now 3× cheaper than previous models ($10/$50 per million tokens). Enables more cost-effective use of Opus for tasks where speed matters.

API: mid-task system prompt updates. Developers can now insert system-level instructions mid-run without breaking prompt cache. Useful for updating permissions or context as agents run.

Coming next: Mythos-class models (beyond Opus) expected to reach general availability in "coming weeks" once cybersecurity safeguards are finalized.
